# Implementation Evidence

This directory contains retained screenshots and supporting evidence from the experimental implementation of the Wazuh-LLM alert enrichment framework.

The materials document selected stages of the original laboratory implementation, including:

- LLaMA 3 installation and execution through Ollama
- Ollama API testing
- Connectivity between the Wazuh server and the Ollama API
- Wazuh-LLM bridge implementation and configuration
- Latency-analysis implementation evidence

These materials are provided as supporting experimental evidence and should be considered alongside the reproducible configuration and source files included in the main repository.
