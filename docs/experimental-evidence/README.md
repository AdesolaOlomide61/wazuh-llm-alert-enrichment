# Experimental Evidence

This directory contains retained screenshots and supporting evidence from the controlled attack scenarios used to evaluate the Wazuh-LLM alert enrichment framework.

The formal evaluation scenarios were:

- Fedora SSH brute-force activity
- Windows authentication / RDP brute-force activity
- SQL injection
- Shellshock (CVE-2014-6271)

The materials include selected raw endpoint logs, Wazuh detections, raw alert evidence, and representative LLM-enriched outputs where retained.

These screenshots are provided as supporting evidence from the original laboratory experiments. They do not constitute a complete raw dataset or a production-scale benchmark.
